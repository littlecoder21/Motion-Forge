# MOTIONFORGE — MASTER PROJECT EVOLUTION PROMPT

## PROJECT OBJECTIVE

Upgrade the existing MotionForge application into a powerful, professional, modern slider, carousel, motion, and interactive presentation builder.

MotionForge is an existing React + TypeScript project.

This is a comprehensive improvement and expansion of the existing project, not a replacement or a complete rewrite.

The objective is to significantly improve the current carousel engine, motion system, 3D capabilities, editor experience, mobile usability, responsive architecture, presets, and export quality while preserving the existing features that already work.

The application must remain a carousel and slider creation tool. Do not turn it into an unrelated animation editor.

The final product should feel like a professional visual creation studio capable of producing advanced website carousels, hero sliders, product showcases, interactive galleries, editorial sliders, 3D presentations, and modern motion-based website components.
